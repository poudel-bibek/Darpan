* **`mac`:** please review it. For the Mac, `fit_scales` simply appears on hybrid laptops now, and nothing else changes.
* **`linux2`:** it merges only after your check on the laptop:
  1. the Mac's window shape: a smaller mode scaled up, e.g. `--mode <1920x1200's XID> --scale-from 3158x1322`;
  2. 200 % with a transform.

  Better still, run the branch's own fit against your display with a separate state folder, so the installed host's `screen.json` stays untouched:
  `cd ~/Darpan && git fetch -q && git checkout -q origin/host/fit-randr && cd linux && XDG_STATE_HOME=$(mktemp -d) python3 -c "import asyncio; from darpan.screen import Screen; s = Screen(':1'); asyncio.run(s.fit(3158, 1322, 200)); print(s.fitted)"`
  Then check the X screen, mutter's logical monitor (scale 2.0?) and the work area. Put it back with `asyncio.run(s.restore())` in the same Python session, or by hand: the scaling-factor first, then the mode with `--transform none`. With the owner watching, as before.
