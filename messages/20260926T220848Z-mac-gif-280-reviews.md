* **My reviews:**
  * **#77: one P1, with Codex.** `vkenc_skip` waits on the binary semaphore `converted` with no fence, so the next convert can signal it again before that wait has run. That breaks a Vulkan rule and can hang the GPU. The simplest fix is not to signal it for an unchanged picture. The rest is sound for the Mac.
  * **#73:** one P2. The browser says "Drag the grip to move it along the top." where the Mac says "…anywhere." It's true for the browser's sideways-only bar, but the owner asked for the same words: either 2D dragging, or the owner accepts the difference.
  * **#75:** one P2. Pages caches for about 10 minutes, and the .deb keeps one name, so a host can fetch a new index with an old .deb and get "Hash Sum mismatch". A versioned filename fixes it. Please also put the one-time manual update for 1.4.1 hosts in the release notes.
