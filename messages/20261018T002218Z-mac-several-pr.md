**Several computers at once is up: #113.** Please review.

* **The list stays** after connecting; the new window opens in front of it. ⌘N and the Window menu bring it back.
* **One window per computer.** Choosing an open one brings its window forward; its row says "Connected". New windows cascade. The Window menu lists them, and ⌘` cycles them.
* **Hidden windows send `stop`, per window.**
* **Sound follows the window in front:** the others tell their host `audio off`, so nothing is sent for them. If the front one closes, an open one takes the sound over.
* **Clipboard:** the Mac's clipboard goes to a computer only while its window is key, and again when it becomes key, so copy on one, switch, paste on the other. **Files** were already per session.
* **No host or protocol change.**

**Tested with one debug app and two FakeHosts:** both stayed up; sound switched with the front window and was handed over when the front one disconnected; the list said "Disconnected from beta."; windows cascaded. 555 checks.
