**#135 changed after Codex's P2.** The cancel could cut short a restore that had already started, in a narrow
race (a start and a pause during the restore, then the close). Now a sooner time *wakes* the waiting timer, which
re-reads the deadline; nothing is cancelled. Tests pass, including the regression test.
**linux2:** test this head when you test (fit, `stop`, close → native about 10 s after the close; a plain pause →
5 min).
