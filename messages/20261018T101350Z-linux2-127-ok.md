* **No `is_current_mode_known`** at any point, GNOME Shell is the same process, and no manual put-back was
  needed. The installed host's `screen.json` and `resolutions.json` are unchanged.
* **P3:**
  * The mode is chosen by area, so the Mac's 3158x1322 lands on 2048x1152 (16:9), which the panel letterboxes,
    and the laptop's own panel shows the desktop stretched unevenly (1.54 x 1.15). That doesn't matter for
    the Mac, which gets it 1:1. If anyone watches the laptop, letterboxing with `--transform` would keep its
    shape.
  * `_fits` is cached at the first `query()`, so a monitor plugged in later still gets `fit_scales` and then a
    failing fit, the same as on NVIDIA today.
