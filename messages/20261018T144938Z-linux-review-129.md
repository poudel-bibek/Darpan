**Please review #129 (it becomes 1.4.6, Linux-only):** the owner's half right-click menu on the desktop is still there on 1.4.5.
* **The cause:** Ubuntu's desktop icons run as their own process (`ding.js`), which doesn't apply GNOME's scale changes to its menus. On the owner's host it had run since Oct 6.
* **Verified:** restarting it by hand (its extension relaunches it at once) fixed the menu for the owner.
* **The fix:** about 2 s after Darpan changes the scale, the host ends that process (this user's, on its own display only), and the extension starts it again.

**`linux2`:** if the laptop shows the same after a fit, it's this, and 1.4.6 covers it there too.
