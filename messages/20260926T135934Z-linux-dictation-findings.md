**Dictation: how the apps insert text** (from their current builds, their docs, and VoiceInk's source). All of them write the pasteboard, then post ⌘V; none types Unicode events or inserts through Accessibility.

| app | ⌘V as posted | pasteboard write | clipboard restore |
|---|---|---|---|
| Wispr Flow 1.6 | the layout's V key, ⌘ **only in the flags**, no ⌘ flagsChanged, to the session tap | lazy (data provider), ConcealedType + string. Not read within ~1 s = "paste failed" | after 500 ms |
| Superwhisper 2.18 | ⌘ only in the flags, HID tap | TransientType | configurable (was 3 s) |
| MacWhisper 15 | `CGEventPostToPid` | ConcealedType + string | yes, delay unknown. **Refuses unless the focused element is a text field** (`noActiveTextFieldFound`), unless "Allow dictation everywhere" is on |
| VoiceInk | real ⌘ (0x37) down, V down/up, ⌘ up, 10 ms apart, HID tap | Transient + AutoGenerated | 2 s default |
| Aqua Voice | ⌘ only in the flags, HID tap | sometimes Transient/Concealed | yes |
| Apple Dictation | NSTextInputClient: marked text for interim words, `insertText` for the result (may arrive outside key-event processing). `selectedRange` must not be `{NSNotFound, 0}` or it aborts; ours returns location 0, fine | none | n/a |

Wispr's docs say the stray "v" "happens in multiple Mac remote-desktop clients". Those track ⌘ through flagsChanged only.

**What I'd change in the viewer, in order:**
1. **A flags-only ⌘ must not stay down.** The translator presses ControlLeft from the V event's flags, but no event ever clears it (V's key-up still has `.command`), so the host holds Ctrl until the next key and a click becomes Ctrl+click. When ⌘ was taken from flags alone (no device bits, no ⌘ flagsChanged), release it after that key's up.
2. **Detect paste by character, not key code 9.** Use `charactersIgnoringModifiers == "v"`. Wispr posts the layout's V key, and with Dvorak or AZERTY today's check misses `beforePaste()`, so Linux pastes stale text.
3. **Restore race.** `poll()` should send nothing for ~1 s after `beforePaste()` sent text (Wispr restores at 500 ms, and the X paste request is asynchronous).
4. **Be a text field for apps that check** (MacWhisper): `accessibilityRole` `.textArea`, with the selected-text setter forwarding as `txt`.
5. **Apple Dictation:** check that it works end to end (marked text → `insertText` → `txt`).

`beforePaste()` already reads the pasteboard right away and ignores the Transient/Concealed markers. Keep both: the read is what tells Wispr the paste succeeded.
