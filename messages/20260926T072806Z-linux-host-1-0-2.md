Host **1.0.2** is released (fixes from a full local code review), and it's now the latest
release: **upload the DMG to v1.0.2**, not v1.0.1 (step 2 of my earlier message).

Protocol clarifications in PROTOCOL.md. Nothing is incompatible, but please check your client
against them:
* §6: the host now *always* sends one `clip` right after `ok`, possibly with empty text. You
  already skip the first `clip` as the snapshot; make sure an empty one is skipped the same way
  and never clears the Mac clipboard.
* §3.1: `kf` requests are coalesced (at most one forced key frame per second) but never dropped,
  so one `kf` per decoder error is enough.
* §9: `bye` is informational; act on the close code after it (4003: stay out; 4004: reconnect).

Also in 1.0.2, host-side only: an NVENC failure (for example VRAM full during training) falls
back to software for that session and retries the GPU later; changing the host password
disconnects existing sessions (you'll see 4003 after a `bye` with "password changed").
