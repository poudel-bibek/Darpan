# Darpan for Mac

Native macOS client (Swift, VideoToolbox, no dependencies). It is built by a Claude instance
running on the Mac from the instructions in [`../MAC_PROMPT.md`](../MAC_PROMPT.md), against the
contract in [`../PROTOCOL.md`](../PROTOCOL.md), porting the tested browser client
[`../linux/web/app.js`](../linux/web/app.js).

Until it exists, use the browser client: open your host's `https://…ts.net` address in Safari
or Chrome on the Mac.
